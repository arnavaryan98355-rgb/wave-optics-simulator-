Formula and unit guide

  • Convert slit dimensions from millimetres to metres before substituting in SI equations.
  • Double slit: β = (width of 10 fringes)/10; λ = βd/D.
  • Single slit: y₁ = W/2; λ = y₁a/D; 2θ ≈ W/D.
  • Percentage difference = |calculated λ − reference λ| / reference λ × 100.
  • Use the same screen-distance reference point for all readings. Never look into the laser beam or its reflections.

This is a calculation/observation helper, not a physical optical ray-tracing simulation. Record real readings from your setup and use the PDF values only as reference data.
